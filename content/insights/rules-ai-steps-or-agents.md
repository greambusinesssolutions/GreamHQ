Not every task needs AI. If the answer never changes, a simple rule is faster and cheaper. If a task needs reading a message or drafting a reply, an AI step helps.

An agent is worth it when a job takes several steps, like answering an enquiry, logging it and setting a follow-up, and can be done within limits a person sets.
